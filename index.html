How I build

  • Production-ready by default. Every project ships with the unglamorous parts done: auth, billing, background jobs, CI/CD, deployment. If it can't survive real users, it isn't finished.
  • AI-assisted, deliberately. I use AI tooling to move faster on the repetitive parts — the architecture, code review, and quality bar stay mine. That's how weeks replace months without cutting corners.
  • Full-stack ownership. Architecture through deployment, one pair of hands: database schema, API design, frontend, infrastructure. No hand-offs, no gaps between layers.
  • Ship, then sharpen. Working software in production first, polish second. Each project above went from idea to a deployed, usable product — then kept improving.
